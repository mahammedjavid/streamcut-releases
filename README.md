# StreamCut for Mac and Windows

Download the StreamCut app from the [latest release](https://github.com/mahammedjavid/streamcut-releases/releases/latest):

| Your computer | File |
|---|---|
| Mac with Apple Silicon (M1 or later) | `StreamCut-<version>-mac-arm64.dmg` |
| Windows 10 or 11 (64-bit) | `StreamCut-<version>-win-x64.exe` |

StreamCut records and clips your streams on your own computer, with your own Claude (the Creator plan). Rather not install anything? StreamCut credits do it all for you — see [streamcut.kliptic-clips.workers.dev](https://streamcut.kliptic-clips.workers.dev/#pricing).

This repository only hosts the installers; there is no source code here.

## First open

<a id="first-open"></a>

**Mac**: open the .dmg and drag StreamCut to Applications. The first time, macOS says it can't check the app:
- macOS 15 (Sequoia) and later: click **Done**, open **System Settings → Privacy & Security**, scroll to "StreamCut was
  blocked…", click **Open Anyway**, then **Open Anyway** again and enter your password.
- macOS 14 and earlier: **right-click** (or Control-click) StreamCut in Applications → **Open** → **Open**.

It's only needed once. StreamCut then appears in the menu bar (top right).

**Windows**: run `StreamCut-<version>-win-x64.exe`. If Windows SmartScreen says "Windows protected your PC", click
**More info** → **Run anyway**. It installs for you only (no admin password) and starts in the notification area
(bottom right; it may be under the ^ arrow).
